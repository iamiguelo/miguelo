# miguelo.com

Web de miguelo.com: vídeo del logo a pantalla completa (vertical en móvil, horizontal en ordenador) y pie con contacto.

Es una web estática, sin compilación. Se publica con Cloudflare Pages desde la rama `main`.

- `index.html`: la página
- `video/`: `miguelo-16x9.mp4` (ordenador) y `miguelo-9x16.mp4` (móvil)
- `assets/`: logos
